# v1.0.3 Planning

## Overlay Visibility Modes

Add overlay visibility controls for driver state:

- in car
- out of car
- spotting
- garage

Evaluate whether these should replace or take priority over the current practice / qualifying / race visibility settings. The goal is to let users express when an overlay is useful by real usage context instead of only by session type.

Open decisions:

- Whether session-type visibility should remain as an advanced filter, become a secondary condition, or be retired.
- Which telemetry signals reliably distinguish in-car, out-of-car, spotting/spectating, and garage/setup states.
- How each overlay should default across those states, especially Pit Service, Inputs, Track Map, Car Radar, Garage Cover, and Stream Chat.
